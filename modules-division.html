PetCare — Division des Modules

Repartition Front-end + Back-end pour 6 personnes

Module 1 — Authentification & Infrastructure

Personne 1
Backend (14 fichiers)
  • Config SecurityConfig, CorsConfig, DataInitializer, application.yml, pom.xml
  • Security JwtAuthFilter, JwtTokenProvider, UserDetailsServiceImpl
  • Controller AuthController.java
  • Service AuthService.java
  • Entity User.java
  • Repository UserRepository.java
  • DTO LoginRequest, RegisterRequest, AuthResponse, UserResponse
  • Exception GlobalExceptionHandler, EmailAlreadyExists, ResourceNotFound, Unauthorized
Frontend (8 fichiers)
  • Pages page.tsx (landing), login, register, pricing
  • Layout Header.tsx, Navbar.tsx, PageContainer.tsx, layout.tsx
  • Hooks useAuth.ts
  • Lib api.ts, utils.ts
  • Types index.ts (types partages)
Socle du projet : Spring Security + JWT + gestion des roles (owner / veterinarian)

Module 2 — Gestion des Animaux + Export

Personne 2
Backend (6 fichiers)
  • Controller AnimalController.java
  • Service AnimalService.java
  • Entity Animal.java
  • Repository AnimalRepository.java
  • DTO CreateAnimalRequest, UpdateAnimalRequest, AnimalResponse
  • Enums Species.java, Gender.java
Frontend (5 fichiers)
  • Pages animals/, animals/new, animals/[id]
  • Composants components/animals/QRCodeCard.tsx
  • Lib pdf-export.ts
CRUD complet + upload photo base64 + generation QR (SVG) + export PDF (iframe + print)

Module 3 — Suivi Medical + Vaccinations

Personne 3
Backend (8 fichiers)
  • Controller MedicalRecordController, VaccinationController
  • Service MedicalRecordService, VaccinationService
  • Entity MedicalRecord.java, Vaccination.java
  • Repository MedicalRecordRepository, VaccinationRepository
  • DTO CreateMedicalRecordRequest, MedicalRecordResponse, CreateVaccinationRequest, VaccinationResponse
  • Enum MedicalRecordType.java
Frontend (4 fichiers)
  • Pages tracking/, animals/[id]/medical, animals/[id]/vaccinations
  • Composants components/medical/*
Timeline medicale + statut vaccinal (a jour / en retard / a venir) + 2 controllers

Module 4 — RDV + Rappels + Alimentation

  • Entity Appointment.java, Reminder.java, Meal.java
  • Repository AppointmentRepository, ReminderRepository, MealRepository

Module 5 — Intelligence Artificielle + Poids

  • Service AssistantService, WeightRecordService
  • Entity WeightRecord.java
  • Repository WeightRecordRepository.java
  • DTO AssistantRequest, AssistantResponse, CreateWeightRecordRequest, WeightRecordResponse

Module 6 — Dashboard + Communication + Services

Personne 6
Backend (agregation)
  • DTO ApiErrorResponse.java (partage)
  • Role Consomme les APIs des modules 1-5 pour agreger les donnees dans le dashboard
Frontend (6 pages)
  • Pages dashboard/ — tableau de bord (agrege toutes les donnees)
  • Pages analytics/ — 4 graphiques SVG dessines a la main
  • Pages chat/ — messagerie WhatsApp-like
  • Pages community/ — forum (categories, likes, commentaires)
  • Pages marketplace/ — boutique (18 produits, panier)
  • Pages map/ — carte veterinaire (16 lieux, geolocation)
Le plus de pages frontend (6) — graphiques SVG et interfaces riches compensent le backend leger
